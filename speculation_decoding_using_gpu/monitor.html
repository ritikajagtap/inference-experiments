Speculative Decode Monitor

watch the draft keep the GPU busy while its compute sits idle

Each round the small draft model guesses several tokens one at a time, then the large target model checks them all in a single pass. Compute (SM) is how much of the GPU's math units are working; at batch size one it stays low because each pass is spent re-reading weights from memory. So the draft takes real time but barely uses the GPU's compute.
